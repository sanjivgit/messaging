# mingle

A simple, local-only messaging application UI built with React, TypeScript, Vite, and Tailwind CSS.

## Included flows

- Mobile-number onboarding without OTP verification
- Editable user profile with presence settings
- One-to-one conversations
- Group creation with member selection
- Contacts directory for starting conversations
- Text, image, video, document, audio, and reply message previews
- Local state interactions only — no API or backend integration

## Run locally

```bash
npm install
npm run dev
```

The app starts with a prefilled demo profile. Submit the onboarding form to open the messenger.
